# Kubestronaut Labs

My hands-on study log on the way to the CNCF Kubestronaut certifications:
KCNA, CKA, CKAD, KCSA and CKS.

Everything here is written by me while learning: manifests, break/fix notes,
runbooks and scripts. No course or exam questions are copied.

## Structure
| Folder | What's inside |
|---|---|
| `k8s-basics/` | Pods, deployments, services, YAML |
| `kcna/` | Cloud-native concepts with small hands-on tries |
| `cka/` | Cluster administration labs |
| `ckad/` | Application developer labs |
| `kcsa/` | Security concepts and threat modelling |
| `cks/` | Security hardening labs |
| `troubleshooting/` | Break/fix scenarios: symptom, cause, fix |
| `runbooks/` | Step-by-step operational guides |
| `cheatsheets/` | kubectl, JSONPath and speed-drill notes |
| `scripts/` | Reusable scripts |
